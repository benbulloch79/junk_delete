# junk_delete Staging Bundle

Open Knowledge Format v0.1 bundle for ephemeral content awaiting triage.

**Agent bootstrap:** [AGENTS.md](AGENTS.md) · **Human onboarding:** [README.md](README.md) · **Promotion workflow:** [reference/promotion-workflow.md](reference/promotion-workflow.md)

## Folder indexes

| Folder | Index | Purpose |
|--------|-------|---------|
| Inbox | [inbox/](inbox/) | Unsorted incoming |
| Staging | [staging/](staging/) | Sorted by topic, still ephemeral |
| Reference | [reference/index.md](reference/index.md) | OKF profile, ecosystem map, promotion SOP |
| Tracking | [tracking/index.md](tracking/index.md) | Staging queue and promotion log |
| Imports | [imports/](imports/) | Frozen downloads (optional) |

## Workflow

1. Drop unsorted items in `inbox/`.
2. Sort into `staging/<topic>/` when you know the category.
3. Follow [reference/promotion-workflow.md](reference/promotion-workflow.md) to promote or delete.
4. Log outcomes in [tracking/promotion-log.md](tracking/promotion-log.md).
